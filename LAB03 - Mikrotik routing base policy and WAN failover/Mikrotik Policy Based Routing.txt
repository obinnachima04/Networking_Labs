STEP 5:  CREATE THE ROUTING TABLES
==================================
Before configuring routes, you must define the custom routing tables for your LAN networks.

ROUTING -> TABLES.
    Click the + (Add) icon.
    Set Name to to_WAN1 and check the FIB box. 
    Click OK.

    Click + again. 
    Set Name to to_WAN2, check FIB
    click OK.


STEP 6:  CONFIGURE MANGLE 
==========================
This ensures LAN1 prefers WAN1, LAN2 prefers WAN2, but they can still communicate locally.

Navigate to IP -> Firewall -> Mangle tab.
    Add LAN-to-LAN bypass rules (so local traffic doesn't break):
    Click +. 
    Under General: 
    Chain = prerouting
    Src. Address = 10.1.1.0/24
    Dst. Address = 172.16.1.0/24. 
    Under Action: 
    Action = accept. 
    Click OK.

    Click +. 
    Under General: 
    Chain = prerouting
    Src. Address = 172.16.1.0/24
    Dst. Address = 10.1.1.0/24. 
    Under Action: 
    Action = accept. 
    Click OK.

    Add LAN1 Routing Mark:
    Click +
    Under General:
    Chain = prerouting
    Src. Address = 10.1.1.0/24
    Under Action: 
    Action = mark routing 
    New Routing Mark = to_WAN1.
    Uncheck Passthrough
    Click OK.

    Add LAN2 Routing Mark:
    Click +. 
    Under General: 
    Chain = prerouting
    Src. Address = 172.16.1.0/24
    Under Action: 
    Action = mark routing
    New Routing Mark = to_WAN2
    Uncheck Passthrough
    Click OK.

STEP 8: CONFIGURE LATENCY-BASED FAILOVER (NETWATCH)
=====================================================
If an ISP is online but experiencing terrible latency (e.g., > 150ms due to jitter or ISP congestion), Netwatch will automatically disable the recursive link, triggering the failover.

Navigate to Tools -> Netwatch.
    Monitor WAN1 Latency:
    Click +
    Under Host:
    Host = 1.1.1.1
    Type = icmp
    Interval = 00:00:05
    Thr. Max Latency = 150ms.

Under the Down script tab, paste:
/ip/route/disable [find where gateway=1.1.1.1 and distance=1]
/log warning "WAN1 Latency high or down! Switching LAN1 to WAN2."

Under the Up script tab, paste:
/ip/route/enable [find where gateway=1.1.1.1 and distance=1]
/log info "WAN1 Latency stable. LAN1 returned to WAN1."

Click OK.

    Monitor WAN2 Latency:
    Click +
    Under Host:
    Host = 8.8.8.8
    Type = icmp
    Interval = 00:00:05
    Thr. Max Latency = 150ms.

Under the Down script tab, paste:
/ip/route/disable [find where gateway=8.8.8.8 and distance=1]
/log warning "WAN2 Latency high or down! Switching LAN2 to WAN1."

Under the Up script tab, paste:
/ip/route/enable [find where gateway=8.8.8.8 and distance=1]
/log info "WAN2 Latency stable. LAN2 returned to WAN2."

Click OK.
